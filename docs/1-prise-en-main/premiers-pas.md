Choisissez votre point de départ selon ce que vous voulez suivre. Chaque étape renvoie à la fiche qui la détaille.

## Suivre le flux d’une équipe

1. Importer le projet ou le board Jira de l’équipe, ou un fichier Excel. → Partie 2, fiche [2.2 Importer un produit](../2-produits/importer-produit.md).
2. Faire la première configuration : types de tickets et workflow (les étapes du flux de travail). → Partie 2, fiche [2.3 La première configuration](../2-produits/premiere-configuration.md).
3. Lire le tableau de bord du produit. → Partie 2, fiche [2.4 Les tableaux de bord](../2-produits/produit-tableaux-de-bord.md).
4. Approfondir avec les graphiques, la prévision et l’Analyse 360. → Partie 2, fiches 2.5 à 2.8.

## Suivre la livraison logicielle

1. Importer une vue DORA depuis GitHub ou GitLab. → Partie 4, fiche 4.3 Importer une vue DORA.
2. Lire les Métriques DORA et leur niveau de performance. → Partie 4, fiches 4.1 et 4.4.
3. Lier la vue au produit de la même équipe, pour passer de l’un à l’autre. → Partie 4, fiche 4.7 Les réglages d’une vue.

## Évaluer la maturité d’une équipe

1. Créer un modèle d’évaluation, ou utiliser un modèle existant. → Partie 6, fiche 6.2 Les modèles.
2. Créer l’évaluation de l’équipe et la lier à son produit. → Partie 6, fiche 6.3 Les évaluations d’équipe.
3. Saisir une première mesure avec l’équipe, puis suivre sa progression. → Partie 6, fiche 6.3.

## Passer à l’échelle de plusieurs équipes

- Métriques de flux : créer un programme à partir des produits des équipes. → Partie 3.
- Métriques DORA : créer un programme DORA à partir de leurs vues. → Partie 5.
- Évaluations : créer un programme d’évaluations. → Partie 6, fiche 6.4.

## Aller plus loin

- Demander une analyse à Alice sur un graphique ou un sprint. → Partie 7.
- Construire vos propres tableaux de bord. → Partie 2, fiche 2.9 Réglages.
- Interroger vos données depuis Claude avec l’accès MCP. → Partie 8, fiche 8.5.
